CODEDETECTIVE — QR АРҚЫЛЫ АШЫЛАТЫН ОНЛАЙН НҰСҚА

1) github.com сайтына тіркеліңіз немесе кіріңіз.
2) New repository → мысалы codedetective-school → Create repository.
3) Add file → Upload files арқылы осы CodeDetective бумасының ІШІНДЕГІ файлдарды (app.py, requirements.txt, render.yaml, templates, static) жүктеңіз. ZIP файлын сол күйі жүктемеңіз. Commit changes басыңыз.
4) render.com сайтына кіріңіз → New → Blueprint (егер қолжетімді болса) → GitHub репозиторийін қосыңыз → render.yaml негізінде Deploy.
   Егер Blueprint қолжетімсіз болса: New → Web Service → GitHub репозиторийін таңдаңыз; Runtime: Python; Build command: pip install -r requirements.txt; Start command: gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 4 app:app; SECRET_KEY орталық айнымалысына ұзын кездейсоқ мән беріңіз.
5) Deploy аяқталғанда Render https://...onrender.com мекенжайын береді. Оны өз телефоныңыздан ашып тексеріңіз.
6) Нақты HTTPS сілтемені ChatGPT-ке жіберіңіз. Сол сілтеме бойынша QR-код жасауға болады.

МАҢЫЗДЫ:
- Қазіргі жергілікті 38 тексеру онлайн нұсқаға АВТОМАТТЫ ТҮРДЕ көшпейді.
- Тегін Render жоспарында жергілікті SQLite файлындағы жаңа статистика қайта орналастыру/қайта іске қосу кезінде жоғалуы мүмкін. Тұрақты статистика үшін тұрақты сыртқы дерекқор қажет.
- Тегін инстанс ұйқы режимінен оянғанда алғашқы ашылу баяулауы мүмкін. Қорғау алдында тексеріңіз.
- Бұл нұсқа Python кодын тікелей орындамайды; AST және қарапайым статикалық ережелер арқылы тексереді.
- Жоба бастапқыда сыртқы Chart.js CDN қолданады; телефон интернетке қосулы болса диаграмма жүктеледі.
- Жобаны жалпыға жарияламас бұрын қауіпсіздік пен жүктеме сынағын өткізу керек.
