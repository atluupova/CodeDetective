CodeDetective Pro - іске қосу / запуск / run

1) Python 3 орнатыңыз.
2) Осы папкада Terminal / PowerShell ашыңыз.
3) Бір рет: pip install -r requirements.txt
4) Іске қосу: python app.py
5) Браузер: http://127.0.0.1:5000

Жаңа бөлімдер:
- Dashboard / Панель
- Code Lab (AST safe checker)
- 15 practice exercises + progress
- Research Mode: pre-test -> practice -> post-test
- Statistics
- KZ / RU / EN

Ескерту: Chart.js интернеттен жүктеледі. Интернет болмаса, сайттың негізгі функциялары жұмыс істейді, тек статистика диаграммасы көрінбеуі мүмкін.
